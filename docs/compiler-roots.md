# Existing programs under the pinned compiler

The Simplicity programs in the wallet kit (`ConcatenaLabs/SWK`, `lwk_simplicity/data/`) and in OpenDAMP (`ConcatenaLabs/openamp`, `opendamp/programs/`) are built with SimplicityHL 0.4.1. This page compiles each with the arguments its own repository uses, under 0.4.1 and under the compiler this repository pins (0.7.2), and compares the commitment roots with each other and with the roots those repositories record.

Compared at SWK `87a9f5e7f` and openamp `a4a84c422`. Generated by `tools/compiler-roots/compare.py`, which links both compilers into one binary; the full output, arguments included, is `tools/compiler-roots/roots.json`.

## Choice for each program

| Program | Choice |
|---|---|
| SWK `p2pk.simf` | Same root under both compilers. SWK can take the pinned compiler from this crate with no address change. |
| SWK `p2pk.simf`, with debug symbols | The recorded vector is a debug-symbol build and holds under both compilers. Debug symbols change the root (compare the row above), so a vector for a deployed contract is always a build without them. |
| SWK `options.simf` | Same root. Upstream's option contract, LBTC-collateral only and with no Sequentia caller: it stays in SWK as upstream code and is not carried into this repository. |
| SWK `seqob_fill.simf` | Same root. An experiment, not the shipped order book (which is tapscript), with a literal expiry height: it stays in SWK and is not carried here unchanged. |
| SWK `seqob_partial.simf` | Same root. An experiment, as above; a successor belongs here only rewritten as a contract with its regtest test. |
| SWK `seqob_xchain_seqleg.simf` | Same root. An experiment, as above; the cross-chain leg in production is a tapscript HTLC. |

| OpenDAMP `issuer.simf` (G) | Same root as the recorded vector; moves with U. |
